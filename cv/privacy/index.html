Privacy

A small, first-party analytics footprint.

This portfolio uses a custom analytics system to understand whether the site is useful and how people find it. The system is designed to collect less data than a typical advertising analytics setup.

What is recorded

Page views, anonymous sessions, broad country/region, device type, browser family, referral source, campaign tags, section views, useful link clicks, approximate engaged time and scroll depth.

What is not stored

Raw IP addresses and raw browser user-agent strings are not stored. A one-way keyed hash is created at request time so aggregate visitor counts can work, then the raw network and browser values are discarded. The site does not use this analytics system to identify visitors by name.

Your browser preferences

The tracker does not run when your browser sends Global Privacy Control or Do Not Track. The analytics tracker does not use advertising cookies.

Purpose

The data is used to understand portfolio traffic, which work people explore, and which contact or résumé actions are useful. It is not sold or used for ad targeting.
