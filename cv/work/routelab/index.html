Why I made it

I wanted to see my own days. Where do I go? How far do I walk? How much of my time goes to the road?

I wanted to find out if I could make a useful tool around a hard problem: changing locations, uncertain GPS points and trips that need to make sense later.

What it does

  • Plan a trip on foot or by car. Add up to eight stops and let it find a good order.
  • Record a walk, a run or a drive, then save it.
  • Look back at your history and see where your time went.

Phones are not always honest.

GPS can jump across town, go blurry, or wobble while you stand still. RouteLab checks every point before it counts.

How it works

Every GPS point must answer four questions. Is it fresh? Is it sharp enough? Did I really move? Could a person move that fast?

Only the points that pass get saved. Distance follows the curve of the Earth, using the Haversine formula.

What it cannot do yet

It only records while the app is open. Phones pause apps in the background, and I would rather say so than pretend.

It also has no live traffic. Maybe one day.

Decisions I made

I chose what the map should show and how each trip should be recorded. I set checks for old, uncertain and unlikely GPS points so they would not distort the trip history.

I use AI coding tools to build the features, then review the behaviour and test what comes back. The hard part is deciding what counts as a useful and reliable result.
