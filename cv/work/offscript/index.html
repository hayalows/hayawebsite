Why I made it

Pitch Night started as one event with its own website. Then the idea grew. OffScript became the family name for more events.

So the old event site needed a new home, one that could hold many events without rebuilding what already worked.

How I joined the sites

I chose to keep the existing event pages working. A Cloudflare Worker adds the OffScript header, footer, fonts and logo links as each page loads.

That way, the old event site can stay in place while visitors use one shared home.
